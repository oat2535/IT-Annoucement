# Project Guidelines & Rules

## Slash Commands & Skills

### `/ask-matt`
- When the user prefixes their prompt with `/ask-matt` (e.g. `/ask-matt <คำถามหรือรายละเอียดงาน>`):
  1. Follow the guidance in [.agents/skills/ask-matt/SKILL.md](file:///c:/IT%20Annoucement/.agents/skills/ask-matt/SKILL.md).
  2. Act as the Ask Matt router: determine which development workflow or engineering flow fits the user's situation (e.g. idea -> ship, bug diagnosis, architecture improvement, code review, triage, or wayfinder) and guide them step-by-step.
